# DENTIDESK

- **URL**: https://www.dentidesk.com/
- **Fecha de investigación**: 2026-11-25
- **Proveedor / país**: DENTIDESK (CEO Carolina Calderón; oficina en Providencia, Santiago) / Chile
- **Región asignada**: Latinoamérica

## Problema que resuelve
Gestión administrativa y clínica de clínicas dentales: agenda con confirmación por email, fichas por especialidad (odontograma, endodoncia, periodoncia, ortodoncia, cirugía ortognática), presupuestos, liquidación por producción, reportes e integración de facturación con el SII chileno. Fuentes: https://www.dentidesk.com/ ; https://www.dentidesk.com/dentidesk/feature

## Usuarios objetivo
Clínicas dentales, centros médicos, instituciones académicas (DENTIDESK Académico) y sindicatos con área de salud. Fuente: https://www.dentidesk.com/

## Features detectadas
- Agenda con duración configurable (15, 30, 40 min), bloqueo automático por feriados, correo de confirmación un día antes con opción de confirmar/anular, botón de agendamiento online para el sitio web (Afirmación comercial): https://www.dentidesk.com/dentidesk/feature
- Odontograma (notación chilena, internacional y universal), fichas de periodoncia, carga de radiografías (jpg/png/gif), presupuestos de tratamiento, liquidación por producción, convenios, permisos, reportes (agenda, producción, recaudación, morosos) (Afirmación comercial): https://www.dentidesk.com/dentidesk/feature ; https://www.dentidesk.com/
- Multisucursal, inventario, reporte REMASEP (Chile), apps móviles; WhatsApp automático y consentimiento automático "próximamente" (Afirmación comercial): https://www.dentidesk.com/
